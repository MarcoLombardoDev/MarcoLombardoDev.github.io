Proteus

Cambia l'aspetto di centinaia di file, senza cambiare dove si trovano.

Vedi il repository

Proteus — il nome viene dal dio marino capace di cambiare forma — serve alla sostituzione in blocco di loghi e file grafici in un intero albero di cartelle: un file server aziendale, il checkout di un sito, una condivisione di rete.

Trova i file che corrispondono a un pattern, abbina ciascuno alla sostituzione più adatta, e mostra un'anteprima prima/dopo di ogni singolo abbinamento prima di scrivere qualsiasi cosa. Solo dopo la tua conferma sovrascrive — in modo atomico, con backup recuperabili.

Farlo a mano su centinaia di file è lento e, peggio, silenziosamente rischioso: è facile finire per mettere un banner al posto di una favicon. Proteus automatizza la ricerca e l'abbinamento, ma lascia deliberatamente la persona al centro, con un grado di qualità che dice dove l'automazione è sicura e dove sta indovinando.

  • Piattaforma
    Desktop — Windows, macOS, Linux
  • Sicurezza
    Backup automatici e recuperabili
  • Lingua interfaccia
    Italiano · Inglese
  • Licenza
    AGPL v3 (licenza commerciale disponibile)
Cosa puoi fare
  • Cerca con pattern e wildcard multipli, anche su condivisioni di rete difettose
  • Abbina ogni file alla sostituzione più vicina per risoluzione e nome, con un grado di qualità
  • Permette di correggere a mano un abbinamento con un doppio clic
  • Scrive in modo atomico: nessun file resta troncato a metà in caso di errore
  • Esegue una simulazione completa (dry run) senza toccare alcun file
  • Ripristina tutto con un clic dai backup, in qualsiasi momento
