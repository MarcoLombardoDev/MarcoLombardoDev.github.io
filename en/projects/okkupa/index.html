Okkupa

Fewer emails to book a room, more time to actually use it.

Open the site

Okkupa models an organization the way its physical space actually works: a site splits into areas, an area holds resource types — desks, meeting rooms, parking spots — and each type groups the individual bookable resources. The same structure serves a small coworking space and a multi-site company without switching tools.

A user can belong to several organizations from the same account — useful for consultants and multi-site operators — and sees resources on a map, not just a calendar. Check-in can be mandatory, with automatic release if it doesn't happen, and each area can carry its own hours and maximum booking length.

On the admin side, an access-control module verifies identity by QR code or short code and logs every event; a dashboard shows occupancy and trends in real time, while a separate audit view makes every major system event searchable and exportable.

  • Platform
    Web app + native Android app
  • Model
    Organization → sites → areas → resources
  • Access control
    QR code or short-code verification
  • Roles
    Superadmin, admin, operator, user
What you can do
  • Organizes sites, areas and resources on a map of the space, not just a calendar
  • Lets people join multiple organizations and switch between them from one account
  • Controls physical access by QR code or short code, recognizing the user instantly
  • Enforces time-slot and maximum-duration rules, with check-in and automatic release
  • Distinguishes roles between superadmin, administrator, operator and user
  • Keeps a real-time dashboard and an exportable audit trail of every event
